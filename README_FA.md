# دیبان برای اندروید

همان موتور پایتونی نسخه‌ی دسکتاپ (پوشه‌های `core`، `proxy`، `relay` بدون تغییر) با Chaquopy داخل برنامه اجرا می‌شود.
رابط فارسی با Kotlin نوشته شده و حالت وی‌پی‌ان با `VpnService` و `hev-socks5-tunnel` (داخل `app/src/main/jni`) ساخته می‌شود.

```
برنامه‌ها ← TUN ← hev-socks5-tunnel (DNS نگاشتی) ← SOCKS5 روی 127.0.0.1:1080 ← موتور دیبان ← گوگل ← رله
```

## ساخت
1. Android Studio (نسخه‌ی Koala یا جدیدتر) را باز کنید و این پوشه را Open کنید.
2. از SDK Manager گزینه‌ی **NDK (Side by side)** را نصب کنید.
3. Build ← Build APK یا `./gradlew assembleDebug` (بار اول به اینترنت نیاز دارد).
4. اگر پکیج `cryptography` برای نسخه‌ی پایتون پیدا نشد، در `app/build.gradle.kts` مقدار `version = "3.12"` را به `"3.11"` تغییر دهید.

## نکات مهم
- گواهی MITM باید در تنظیمات اندروید نصب شود (برنامه راهنمای قدم‌به‌قدم دارد). اندروید ۷ به بالا گواهی کاربر را فقط در مرورگرها (کروم) قبول می‌کند و بیشتر برنامه‌های دیگر آن را رد می‌کنند؛ این محدودیت خود اندروید است.
- ترافیک UDP (مثل QUIC) از رله عبور نمی‌کند و مرورگر خودش به TCP برمی‌گردد.
- فقط IPv4 از تونل عبور می‌کند.
- حالت «فقط پراکسی» پراکسی محلی 8085 و SOCKS5 روی 1080 را روشن می‌کند.
- این پروژه روی دستگاه واقعی ساخته و آزمایش نشده است؛ بخش پایتون با موتور اصلی تست شده، ولی Kotlin و NDK را باید اولین بار شما کامپایل کنید.

## ساخت APK بدون نصب ابزار (GitHub Actions)
1. یک مخزن خصوصی در GitHub بسازید و محتوای این پوشه را آپلود کنید (همراه پوشه‌ی `.github`).
2. به تب Actions بروید و کار «Build APK» را اجرا کنید (Run workflow).
3. بعد از چند دقیقه فایل `Diban-debug-apk` را از پایین صفحه‌ی همان اجرا دانلود کنید و `app-debug.apk` را روی گوشی نصب کنید.
